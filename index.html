⚡ Mail 100 % prêt avec un Raccourci iOS

Une page web ne peut pas pré-remplir le destinataire d'un mail avec pièces jointes. Un Raccourci le fait :

  1. App Raccourcis → + → nomme-le « Notes de frais ».
  2. Ajoute l'action Envoyer un e-mail.
  3. Destinataire : ton adresse compta. Objet : « Notes de frais ». Dans le message, insère la variable Entrée du raccourci (= les PDF).
  4. Réglages du raccourci (ⓘ) : active Afficher dans la feuille de partage, type accepté : Fichiers.
  5. Option : désactive « Afficher la fiche de composition » pour un envoi direct.

Ensuite : Envoyer → Partager → « Notes de frais ». (Les intitulés peuvent varier un peu selon la version d'iOS.)

📲 Installer sur l'écran d'accueil

Dans Safari : Partager → « Sur l'écran d'accueil ». Envoie tes tickets régulièrement : iOS peut effacer les données d'un site non utilisé pendant plusieurs semaines.
