⚡ Envoi en 1 geste avec un Raccourci iOS

Le partage web ne peut pas pré-remplir le destinataire. Un Raccourci le fait :

  1. Ouvre l'app Raccourcis → + → nomme-le « Notes de frais ».
  2. Ajoute l'action Envoyer un e-mail.
  3. Destinataire : ton adresse compta. Objet : « Notes de frais ». Dans le message, insère la variable Entrée du raccourci (= les PDF en pièces jointes).
  4. Dans les réglages du raccourci (ⓘ) : active Afficher dans la feuille de partage, type accepté : Fichiers.
  5. Option : désactive « Afficher la fiche de composition » pour un envoi direct.

Ensuite : Envoyer → Partager → choisis « Notes de frais » dans la liste. (Les intitulés peuvent varier un peu selon la version d'iOS.)

📲 Installer sur l'écran d'accueil

Dans Safari : bouton Partager → « Sur l'écran d'accueil ». L'app s'ouvre alors en plein écran. Conseil : envoie tes tickets régulièrement, iOS peut effacer les données d'un site non utilisé pendant plusieurs semaines.
